# Further recommended readings
---
I found these resources really useful while developing a programming style for this project.

`19950022400.pdf`: 
NASA Critical Flight C programming style standards

`jpl-c-1.0.pdf`: 
Jet Propulsion Laboratory's Institutional Coding Standard for the C programming language.

`ISBN-13: 978-1-72112-798-6`: 
Embedded C coding standard by Michael Barr.
Copyright 2018 Integrated Embedded, LLC (dba Barr Group)

`MISRA-C:2023 + C:2025 + All applicable addendum`:
Cost's $25, MATLAB has really good help pages that summarize the guidelines instead.
